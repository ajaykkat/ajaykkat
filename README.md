# Hi, I’m Ajay Kattevirupu

### AI agents · Retrieval pipelines · Language models

I build Python projects that connect language models to practical workflows, and explore how those models work under the hood. My work spans job-search assistants, semantic matching, agent infrastructure, and training small transformers.

## Featured FDE project

[Logistics Hybrid RAG](https://github.com/ajaykkat/logistics-hybrid-rag) — a synthetic logistics evidence workbench with BM25 and dense LSA retrieval, rank fusion, reranking, customer-scoped citation checks, and reproducible evaluation. Includes a local UI, 27 tests, and a customer discovery and pilot guide. The README reports measured results and limitations, including where hybrid does not beat BM25.
